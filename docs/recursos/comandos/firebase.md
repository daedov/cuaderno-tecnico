# Firebase CLI
| Comando | Descripción |
|---------|-------------|
| `firebase login` | Iniciar sesión en Firebase |
| `firebase init` | Inicializar proyecto Firebase en el directorio actual |
| `firebase projects:list` | Listar proyectos de Firebase |
| `firebase use <proyecto>` | Seleccionar proyecto activo |
| `firebase deploy` | Desplegar todos los recursos configurados |
| `firebase deploy --only hosting` | Desplegar solo Firebase Hosting |
| `firebase deploy --only functions` | Desplegar solo Cloud Functions |
| `firebase deploy --only firestore:rules` | Desplegar solo reglas de Firestore |
| `firebase emulators:start` | Iniciar emuladores locales (Firestore, Auth, Functions, etc.) |
| `firebase functions:log` | Ver logs de Cloud Functions |
| `firebase firestore:indexes` | Ver índices configurados de Firestore |
| `firebase firestore:delete <ruta> --recursive` | Eliminar documentos/colecciones de Firestore |
| `firebase hosting:channel:deploy <canal>` | Desplegar a un canal de vista previa |
| `firebase database:get <ruta>` | Leer datos de Realtime Database |
